Featured project

ARGUS — Concurrent Event Investigation Engine

Small teams receive authentication and system events as raw logs, and reading every line means missing the burst of failed logins or the one critical event that matters. ARGUS keeps a local event store, evaluates detection rules concurrently, and hands an investigator a focused timeline instead of a wall of text.

I built it as a dependency-free Java CLI: validated event ingestion into CSV storage, a fixed thread pool evaluating detection rules in parallel, and a per-user investigation view with a risk summary. The detection rules are deliberately explainable — high-severity events and repeated failed logins — so every flag can be traced to a reason, not a black box.

Concurrent rule evaluation
Runnable tasks over a fixed thread pool; each rule runs independently.
Explainable anomalies
Two transparent rules with reasons attached to every detection.
Investigation timeline
Per-user event history with a computed risk summary.
Zero dependencies
Compiles with javac alone; tests run without a framework.
